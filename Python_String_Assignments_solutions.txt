Python String Assignments (Using String Methods)

1. Take a string input and convert it to uppercase.
Solution:
text_1 = input("Enter a string: ")
print(text_1.upper())

2. Take a string input and convert it to lowercase.
Solution:
text_2 = input("Enter a string: ")
print(text_2.lower())

3. Count the total number of characters in a string.
Solution:
text_3 = input("Enter a string: ")
print(len(text_3))

4. Count the number of vowels in a string.
Solution:
text_4 = input("Enter a string: ")
vowels = "aeiouAEIOU"
count_vowels = sum(1 for char in text_4 if char in vowels)
print(count_vowels)

5. Count the number of consonants in a string.
Solution:
text_5 = input("Enter a string: ")
count_consonants = sum(1 for char in text_5 if char.isalpha() and char not in "aeiouAEIOU")
print(count_consonants)

6. Check whether a string starts with a given substring.
Solution:
text_6 = input("Enter a string: ")
sub_6 = input("Enter substring to check start: ")
print(text_6.startswith(sub_6))

7. Check whether a string ends with a given substring.
Solution:
text_7 = input("Enter a string: ")
sub_7 = input("Enter substring to check end: ")
print(text_7.endswith(sub_7))

8. Remove leading and trailing spaces from a string.
Solution:
text_8 = input("Enter a string: ")
print(text_8.strip())

9. Replace all spaces in a string with hyphens (-).
Solution:
text_9 = input("Enter a string: ")
print(text_9.replace(" ", "-"))

10. Find the index of a given character in a string.
Solution:
text_10 = input("Enter a string: ")
char_10 = input("Enter character to find: ")
print(text_10.find(char_10))

11. Count how many times a particular character appears in a string.
Solution:
text_11 = input("Enter a string: ")
char_11 = input("Enter character to count: ")
print(text_11.count(char_11))

12. Split a sentence into words using split().
Solution:
text_12 = input("Enter a sentence: ")
print(text_12.split())

13. Join a list of words into a single string.
Solution:
words_13 = input("Enter words separated by space: ").split()
print(" ".join(words_13))

14. Check whether a string is alphanumeric.
Solution:
text_14 = input("Enter a string: ")
print(text_14.isalnum())

15. Check whether a string contains only alphabets.
Solution:
text_15 = input("Enter a string: ")
print(text_15.isalpha())

16. Check whether a string contains only digits.
Solution:
text_16 = input("Enter a string: ")
print(text_16.isdigit())

17. Capitalize the first character of a string.
Solution:
text_17 = input("Enter a string: ")
print(text_17.capitalize())

18. Convert the first character of each word to uppercase.
Solution:
text_18 = input("Enter a string: ")
print(text_18.title())

19. Swap uppercase characters to lowercase and vice versa.
Solution:
text_19 = input("Enter a string: ")
print(text_19.swapcase())

20. Remove all occurrences of a given character from a string.
Solution:
text_20 = input("Enter a string: ")
char_20 = input("Enter character to remove: ")
print(text_20.replace(char_20, ""))

21. Find the length of a string without using len().
Solution:
text_21 = input("Enter a string: ")
length_21 = 0
for _ in text_21:
    length_21 += 1
print(length_21)

22. Reverse a string using string methods.
Solution:
text_22 = input("Enter a string: ")
print("".join(reversed(text_22)))

23. Check whether a string is a palindrome.
Solution:
text_23 = input("Enter a string: ")
print(text_23 == text_23[::-1])

24. Extract only digits from a string.
Solution:
text_24 = input("Enter a string: ")
print("".join([char for char in text_24 if char.isdigit()]))

25. Extract only alphabets from a string.
Solution:
text_25 = input("Enter a string: ")
print("".join([char for char in text_25 if char.isalpha()]))

26. Find the first and last occurrence of a character.
Solution:
text_26 = input("Enter a string: ")
char_26 = input("Enter a character: ")
print("First:", text_26.find(char_26), "Last:", text_26.rfind(char_26))

27. Check whether a word exists in a sentence.
Solution:
sent_27 = input("Enter a sentence: ")
word_27 = input("Enter a word to check: ")
print(word_27 in sent_27.split())

28. Count the number of words in a sentence.
Solution:
text_28 = input("Enter a sentence: ")
print(len(text_28.split()))

29. Replace a word with another word in a sentence.
Solution:
text_29 = input("Enter a sentence: ")
old_word = input("Enter word to replace: ")
new_word = input("Enter new word: ")
print(text_29.replace(old_word, new_word))

30. Check whether a string is in title case.
Solution:
text_30 = input("Enter a string: ")
print(text_30.istitle())

31. Remove punctuation marks from a string.
Solution:
import string
text_31 = input("Enter a string: ")
print("".join([char for char in text_31 if char not in string.punctuation]))

32. Check whether all characters in a string are lowercase.
Solution:
text_32 = input("Enter a string: ")
print(text_32.islower())

33. Check whether all characters in a string are uppercase.
Solution:
text_33 = input("Enter a string: ")
print(text_33.isupper())

34. Find the ASCII value of each character in a string.
Solution:
text_34 = input("Enter a string: ")
print([ord(char) for char in text_34])

35. Convert a string into a list of characters.
Solution:
text_35 = input("Enter a string: ")
print(list(text_35))

36. Remove duplicate characters from a string.
Solution:
text_36 = input("Enter a string: ")
print("".join(sorted(set(text_36), key=text_36.index)))

37. Find the longest word in a sentence.
Solution:
sent_37 = input("Enter a sentence: ")
words_37 = sent_37.split()
print(max(words_37, key=len) if words_37 else "")

38. Find the shortest word in a sentence.
Solution:
sent_38 = input("Enter a sentence: ")
words_38 = sent_38.split()
print(min(words_38, key=len) if words_38 else "")

39. Check whether a string is a valid identifier.
Solution:
text_39 = input("Enter a string: ")
print(text_39.isidentifier())

40. Count uppercase and lowercase letters separately.
Solution:
text_40 = input("Enter a string: ")
upper_count = sum(1 for char in text_40 if char.isupper())
lower_count = sum(1 for char in text_40 if char.islower())
print("Uppercase:", upper_count, "Lowercase:", lower_count)
