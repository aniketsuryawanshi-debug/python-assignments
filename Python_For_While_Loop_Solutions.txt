Python Assignments: For Loop and While Loop
Topic: Python For & While Loop Assignments with Solutions

1. Print numbers from 1 to 10 using for loop.
Solution:

    print(i)

2. Print numbers from 10 to 1 using for loop.
Solution:

12. Reverse a number using while loop.
Solution:
num = 1234
rev = 0
while num > 0:
    digit = num % 10
    rev = rev * 10 + digit
    num //= 10
print("Reversed:", rev)

13. Check whether a number is palindrome.
Solution:
num = 121
orig = num
rev = 0
while num > 0:
    rev = rev * 10 + num % 10
    num //= 10
if orig == rev:
    print("Palindrome")
else:
    print("Not Palindrome")

14. Print Fibonacci series up to n terms.
Solution:
n = 10
a, b = 0, 1
for _ in range(n):
    print(a, end=" ")
    a, b = b, a + b

18. Print prime numbers between 1 and 50.
Solution:
for num in range(2, 51):
    is_prime = True
    for i in range(2, int(num**0.5) + 1):
        if num % i == 0:
            is_prime = False
            break
    if is_prime:
        print(num)

19. Check whether a number is prime.
Solution:
num = 17
is_prime = True
if num <= 1:
    is_prime = False
else:
    for i in range(2, int(num**0.5) + 1):
        if num % i == 0:
            is_prime = False
            break
print("Prime" if is_prime else "Not Prime")

22. Find sum of even digits in a number.
Solution:

23. Find sum of odd digits in a number.
Solution:
num = 123456
tot = 0
while num > 0:
    d = num % 10
    if d % 2 != 0:
        tot += d
    num //= 10
print("Sum of odd digits:", tot)

24. Count vowels in a string.
Solution:
s = "Hello World"
vowels = "aeiouAEIOU"
count = sum(1 for c in s if c in vowels)
print("Vowels count:", count)

25. Count consonants in a string.
Solution:
s = "Hello World"
vowels = "aeiouAEIOU"
count = sum(1 for c in s if c.isalpha() and c not in vowels)
print("Consonants count:", count)

28. Check whether a number is Armstrong.
Solution:
num = 153
orig = num
order = len(str(num))
tot = 0
while num > 0:
    tot += (num % 10) ** order
    num //= 10
print("Armstrong" if orig == tot else "Not Armstrong")

48. Check whether number is strong number.
Solution:
import math
num = 145
orig = num
tot = 0
while num > 0:
    tot += math.factorial(num % 10)
    num //= 10
print("Strong Number" if orig == tot else "Not Strong Number")

49. Display menu-driven program using while loop.
Solution:
while True:
    print("1. Say Hello\n2. Exit")
    choice = input("Enter choice: ")
    if choice == '1':
        print("Hello!")
    elif choice == '2':
        break
    else:
        print("Invalid choice")
